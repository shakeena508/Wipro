## 📅 Day 1 – Getting Started with SQL

### Topics Covered

* What is SQL?
* Database
* Table
* Row & Column
* Data Types
* Statements
* ER Diagram
* Entities, Attributes, Relationships

### Brief Explanation

**SQL**

* SQL (Structured Query Language) is used to store, retrieve, update, and delete data from databases.

**Database**

* A collection of related tables.

**Table**

* Stores data in rows and columns.

Example

| ID | Name  | Age |
| -- | ----- | --- |
| 1  | Rahul | 20  |

**Row**

* One complete record.

**Column**

* One type of information.

**Data Types**

* INT → Numbers
* VARCHAR → Text
* DATE → Date
* FLOAT → Decimal values

**ER Diagram**

* Used to design databases.

**Entity**

* Real-world object.
  Example: Student

**Attributes**

* Properties of an entity.
  Example: StudentID, Name

**Relationship**

* Connection between tables.
  Example:
  Student → Enrolls → Course

* Create 2 tables manually.
* Identify Primary Key.
* Draw one ER Diagram.

# 📅 Day 3 – ALTER, UPDATE, DELETE

### Topics Covered

* ALTER TABLE
* UPDATE
* DELETE

### Explanation

Add column

```sql
ALTER TABLE Students
ADD Email VARCHAR(50);
```

Update

```sql
UPDATE Students
SET Age=22
WHERE id=1;
```

Delete

```sql
DELETE FROM Students
WHERE id=3;
```

Difference

DELETE removes rows.

ALTER changes table structure.

# 📅 Day 8 – GROUP BY & HAVING

### GROUP BY

Groups rows.

```sql
SELECT Department,
COUNT(*)
FROM Employees
GROUP BY Department;
```

### HAVING

Filters groups.

```sql
SELECT Department,
AVG(Salary)
FROM Employees
GROUP BY Department
HAVING AVG(Salary)>50000;
```

Difference

WHERE → Before grouping

HAVING → After grouping
